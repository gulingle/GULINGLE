### 1.2 权利范围说明

本软件著作权涵盖以下**自有开发**部分的源代码及文档：

1. **AI 内容生成引擎**：商品页/落地页/Blog 生成的 Prompt 模板、上下文组装逻辑、内容审核工作流
2. **多语言本地化系统**：翻译工作流、术语表管理、hreflang 自动化生成
3. **转化组件库**：倒计时、库存紧迫、弹窗、Sticky CTA、信任徽章等组件的配置引擎与渲染逻辑
4. **A/B 测试系统**：实验配置、流量分配、统计显著性计算、胜者自动切换
5. **SEO 自动化模块**：Meta 生成、sitemap 构建、结构化数据、健康检查报告
6. **跨境主题系统**：主题变量、布局引擎、区块编辑器
7. **店铺管理后台**：多店铺、多租户、域名绑定、环境管理
8. **与跨境业务系统集成层**：与 01/05/06/07 系统的数据同步与 API 适配

**不包含**（属于第三方开源或外部服务）：
- Medusa/Saleor 核心电商引擎（若集成）
- Next.js、React、Ant Design 等前端框架
- PostgreSQL、Redis 等数据库
- OpenAI/Claude 等 LLM 模型本身
- Stripe/PayPal 支付网关
- Cloudflare CDN 服务

## 2. 与开源项目边界

### 2.1 参考开源与自有边界

| 开源项目 | 许可证 | 借鉴内容 | 自有知识产权落点 |
|----------|--------|----------|------------------|
| Medusa | MIT | Headless 架构思路、插件体系概念 | 全部业务代码自研，不 fork 登记 |
| Saleor | BSD-3 | GraphQL API 设计参考 | API 设计参考，实现自研 |
| open-design | - | 组件设计规范 | 转化组件库、主题变量系统 |
| Nono | - | DTC 设计语言 | 自有主题模板 |
| Next.js | MIT | SSR 框架 | 框架使用，不登记 |
| Ant Design | MIT | UI 组件 | 组件使用，不登记 |

### 2.2 软著登记策略

1. **登记代码范围**：仅提交自有业务逻辑代码，不包含 node_modules、第三方库
2. **代码鉴别材料**：前 30 页 + 后 30 页源代码（每页 50 行）
3. **文档鉴别材料**：用户手册（本系列文档精简版）前 30 页 + 后 30 页
4. **避免侵权**：不复制 Medusa/Saleor 核心代码，仅参考架构思路

### 2.3 合规声明

- 本软件基于 MIT/BSD 等宽松许可证的开源组件构建，遵守相应许可证要求
- 开源组件清单见 `LICENSES.md`（随产品发布）
- 客户私有化部署时，开源组件许可证义务由客户承担

## 8. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 软著与开源边界不清 | 登记被驳回或侵权纠纷 | 严格代码审查，仅登记自有代码 |
| 软著审批周期长 | 影响商业宣传 | 提前 2 个月准备材料 |
| 竞品功能同质化 | 价格战 | 强化 AI 内容质量、转化组件差异化 |
| 客户数据安全 | 信任危机 | 通过等保/ISO 认证，私有化选项 |
| LLM 成本上涨 | 利润压缩 | Token 配额管理，模型可切换 |
