## 建议落地顺序（实战）

1. **第 1 个月**：01 运营中台 MVP + 02 成片系统 MVP（获客与演示）

3. **第 3 个月**：04 独立站 + 05 AI 客服（扩大客单价）
4. **第 4 个月**：03 后台自动化 + 08 达人 SOP（效率与增长）
5. **第 5 个月**：09 视觉工厂 + 10 多 Agent 中枢（差异化壁垒）

## 开源参考边界（重要）

| 能力层 | 可参考开源 | 自有知识产权落点 |
|--------|------------|------------------|
| Agent 编排 | DeerFlow / OpenClaw / n8n / Dify | 跨境业务工作流、权限、审计 |
| 浏览器自动化 | browser-use / vibe-seller 思路 | 任务策略、多账号隔离、回放 |
| 短视频 | ClipForge / MoneyPrinterTurbo | 带货模板、商品锁定、质检规则 |
| 建站 | Medusa / Saleor | 主题、转化组件、AI 内容模块 |
| 数据采集 | firecrawl | 评分模型、看板、预警规则 |

> 软著与商用产品必须基于**自有改造代码与业务逻辑**，不得整库登记第三方开源项目。
