## 1. 文档概述

### 1.1 编写目的

定义「短视频带货智能脚本与成片生成系统 V1.0」（代号 ClipCommerce）的完整产品需求，覆盖从商品图输入到可发布 MP4 输出的全链路，作为研发、测试、运营验收的基线文档。

### 1.2 术语定义

| 术语 | 定义 |
|------|------|
| 成片 | 最终可导出的 MP4 视频文件 |
| 脚本 | 分镜结构化的口播文案（含时间轴） |
| 卖点 | 从商品图/描述中提取的核心购买理由 |
| TTS | Text-to-Speech 文字转语音 |
| CTA | Call To Action，行动号召（如「点击小黄车」） |
| 可用率 | 运营认为无需大改即可发布的成片比例 |

## 2. 产品背景与目标

### 2.1 市场背景

TikTok Shop 与抖音抖店带货依赖短视频内容测款。中小卖家缺乏专业编导与剪辑，外包成本高（50–200 元/条）、周期长（1–3 天）。AI 可自动生成脚本与配音，但市面工具多为通用图文转视频，缺乏带货逻辑（钩子、痛点、卖点、CTA）与平台规格适配。

### 2.2 产品愿景

让运营人员 **10 分钟内** 从一张商品图产出可发布的带货短视频，批量测款效率提升 5 倍以上。

### 2.3 业务目标（V1.0 MVP）

| 目标 | 量化指标 |
|------|----------|
| 出片速度 | 单条 < 10 分钟（含预览确认） |
| 成片质量 | 可用率 > 50% |
| 批量能力 | 支持 20 条/天/账号队列 |
| 成本 | 单条 API 成本 < 2 元 |
| 商业化 | 5 家种子客户试用 |

### 2.4 成功标准

1. 上传商品图后 3 分钟内生成可预览成片。  
2. 脚本结构包含：开场钩子（3s）、痛点（5s）、卖点（15s）、CTA（5s）。  
3. 导出 9:16 MP4，分辨率 1080×1920，时长 15–60s 可配置。  
4. 禁词命中时拦截导出并提示修改。

## 4. 用户场景

### 4.1 场景一：单 SKU 快速出片

**角色**：短视频运营小王  
**流程**：
1. 上传商品主图（JPG/PNG，≤ 5MB）。  
2. 可选填写：商品名、价格、目标平台（TikTok/抖店）、视频时长（30s）、语言（中文/英文）。  
3. 系统 OCR + LLM 提取 3–5 个卖点。  
4. 小王确认/编辑卖点，选择脚本模板「痛点型」。  
5. 系统生成脚本（含分镜时间轴）与 2 版备选。  
6. 小王选择配音音色「女声-活力」，预览 TTS。  
7. 系统自动生成字幕（可改样式：白字黑边/黄字）。  
8. 合成预览，小王微调字幕后导出 MP4。  
9. 可选：上传至 TikTok 草稿箱（需授权）。

**验收**：全流程 < 10 分钟；成片可播放；字幕与配音同步。

### 4.2 场景二：批量测款 10 个 SKU

**角色**：运营主管  
**流程**：
1. 上传含 10 个 SKU 的 Excel（图片 URL、商品名、卖点备注）。  
2. 批量创建任务，选择统一模板「性价比型」。  
3. 任务队列执行，失败项标红可重试。  
4. 审核员批量预览，通过 8 条、驳回 2 条（禁词）。  
5. 导出 8 条 MP4 至本地文件夹。

**验收**：10 条任务 2 小时内完成；成功率 > 80%。

### 4.3 场景三：A/B 脚本测款

**角色**：投流运营  
**流程**：
1. 同一商品图创建 2 个任务，分别选「悬念型」「痛点型」模板。  
2. 导出 2 条成片，手动上传投流。  
3. 系统记录脚本版本与模板，供后续 ROI 复盘关联。

**验收**：同商品可关联多脚本版本。

| 需求 ID | 描述 | 验收标准 |

| F02-01 | 图片上传 | JPG/PNG/WebP；单张 ≤ 5MB |

```json
{
  "selling_points": [
    {"text": "超长续航 72 小时", "type": "feature", "priority": 1},
    {"text": "比大牌便宜 50%", "type": "price", "priority": 2}
  ],
  "target_audience": "18-35 岁通勤族",
  "tone": "活泼"
}
```
