# 短视频带货智能成片系统

> **软件登记名**：短视频带货智能脚本与成片生成系统 V1.0  
> **产品代号**：ClipCommerce  
> **版本**：V1.0 MVP  
> **最后更新**：2026-07-19

## 1. 产品定位

面向 TikTok Shop、抖音抖店带货场景的 **「商品图 → 卖点 → 脚本 → 配音字幕 → 导出成片」** 一站式短视频生产系统。  
将单张商品图在 10 分钟内转化为可发布的带货短视频，降低内容生产成本，提升测款效率。

### 1.1 解决的核心痛点

| 痛点 | 现状 | 本产品方案 |
|------|------|------------|
| 视频制作成本高 | 外包 50–200 元/条，周期长 | 单条成本 < 2 元（API 费），10 分钟出片 |
| 脚本缺乏带货逻辑 | 运营不会写钩子与 CTA | AI 按平台模板生成结构化脚本 |
| 多平台规格不一 | 9:16/1:1 需重复制作 | 一次生成多尺寸导出 |
| 批量测款效率低 | 10 个 SKU 需 10 次手工 | 批量任务队列 + 模板复用 |
| 发布链路断裂 | 导出后手工上传 | 对接 TikTok/抖店发布 API（MVP 半自动） |

### 1.2 产品边界

**做：**
- 商品图上传与卖点提取（OCR + LLM）
- 带货脚本生成（钩子/痛点/卖点/CTA 结构）
- TTS 配音（多音色、多语言）
- 字幕自动生成与样式模板
- 视频合成（图片轮播/ Ken Burns / 简单转场）
- MP4 导出（9:16、1:1）
- TikTok / 抖店发布对接（MVP：导出 + 发布草稿）

**不做（V1.0）：**
- 真人出镜拍摄与剪辑
- 复杂 AE 级特效
- 直播切片与混剪
- 达人佣金结算（见 08 号产品）
- 全自动无人发布（需人工确认）

## 2. 目标用户

| 角色 | 场景 | 诉求 |
|------|------|------|
| 短视频运营 | 日更 3–10 条带货视频 | 快、稳、可批量 |
| 店主/小团队 | 自己测款投流 | 低成本、上手快 |
| MCN/代运营 | 多账号多 SKU | 模板复用、账号隔离 |
| 内容审核 | 质检发布前内容 | 禁词、合规拦截 |

## 5. 核心流程

```text
商品图上传 ──► 卖点提取 ──► 脚本生成 ──► 配音(TTS) ──► 字幕叠加 ──► 视频合成 ──► 导出/发布
     │              │            │            │              │
     └──────────────┴────────────┴────────────┴──────────────┘
                           模板库 + 禁词校验 + 人工预览确认
```

## 6. 关键指标

| 指标 | V1.0 目标 |
|------|-----------|
| 单条成片时长 | < 10 分钟（含人工预览） |
| 成片可用率 | > 50%（无需大改即可发布） |
| 批量任务成功率 | > 90% |
| 配音自然度评分 | > 4.0/5.0（内部评测） |
| 发布成功率 | > 95%（对接平台后） |
