# 03-实战运营手册

> **软件名称**：短视频带货智能脚本与成片生成系统 V1.0  
> **适用版本**：V1.0 MVP  
> **最后更新**：2026-07-19

---

## 1. 手册目的

本手册供 **短视频运营、内容审核、投流运营、客成** 直接执行日/周/月 SOP，含 KPI、异常处理、角色职责与验收标准。

## 3. KPI 指标体系

### 3.1 生产效率 KPI

| KPI | 公式 | 日目标 | 周目标 | 月目标 |
|-----|------|--------|--------|--------|
| 日出片量 | 完成导出 MP4 数 | ≥ 3/人 | ≥ 15/人 | ≥ 60/人 |
| 单条耗时 | 上传到导出中位数 | < 15min | < 12min | < 10min |
| 成片可用率 | 无需大改即可发布 / 总数 | ≥ 45% | ≥ 50% | ≥ 55% |
| 批量成功率 | 成功 / 批量任务数 | ≥ 85% | ≥ 90% | ≥ 92% |
| 审核通过率 | 一次通过 / 提交审核 | ≥ 70% | ≥ 75% | ≥ 80% |

### 3.2 质量 KPI

| KPI | 目标 |
|-----|------|
| 禁词漏放率 | 0% |
| 字幕错位投诉 | < 5% |
| 投流后 3s 跳出率（对比手工） | 不高于手工基线 10% |
| 视频完播率（内部测款） | 追踪，不设硬性线 |

### 3.3 成本 KPI

| KPI | 目标 |
|-----|------|
| 单条 API 成本 | < 2 元 |
| 存储占用 | < 租户配额 80% |
| 合成失败重试率 | < 15% |

## 4. 每日 SOP

### 4.1 内容运营 — 日流程

| 时间 | 步骤 | 操作 | 产出 | 异常 |
|------|------|------|------|------|
| 09:00–09:20 | 任务队列检查 | 查看昨日 failed/completed | 重试清单 | §7.1 |
| 09:20–09:40 | 选品对齐 | 确认今日测款 SKU 清单（5–10 个） | SKU 表 | - |
| 09:40–12:00 | 批量创建 | 上传商品图/Excel 批量建任务 | 任务队列 | 图片失败→换源 |
| 12:00–12:30 | 卖点确认 | 审核 AI 卖点，必要时手改 | 确认卖点 | - |
| 14:00–15:30 | 脚本选择与预览 | 选模板；预览 TTS+字幕 | 待审成片 | 音质差→换音色 |
| 15:30–16:30 | 提交审核 | 导出前提交审核员 | 审核队列 | 禁词→修改重提 |
| 16:30–17:30 | 导出归档 | 审核通过→导出 MP4→命名规范 | MP4 文件夹 | §7.2 |
| 17:30–18:00 | 交付投流 | 移交投流或上传草稿箱 | 交付记录 | - |

### 4.2 审核员 — 日流程

| 时间 | 操作 |
|------|------|
| 10:00 / 15:00 / 17:00 | 三轮审核，每轮目标清空队列 |
| 抽检项 | 禁词、CTA 完整性、时长、字幕同步 |
| 驳回 | 必须填写原因标签：禁词/脚本/音质/画面/其他 |

### 4.3 投流运营 — 日流程

| 时间 | 操作 |
|------|------|
| 17:00–18:00 | 领取当日 MP4，按命名上传平台 |
| 记录 | 脚本模板 ID、商品 SKU、上传时间（用于 ROI 关联） |
| 次日 | 记录 3s 跳出率、CTR（如有投流数据） |

### 4.4 文件命名规范

```text
{日期}_{平台}_{SKU}_{模板}_{版本}.mp4
例：20260719_TikTok_EB001_痛点型_v2.mp4
```

### 4.5 运营日报模板

```markdown
## 成片日报 — {姓名} — {日期}

- 创建任务：__ 条
- 完成导出：__ 条
- 审核通过：__ 条 / 驳回：__ 条
- 可用率自评：__%
- 单条耗时中位数：__ min
- 异常：...
- 明日 SKU：...
```

## 5. 每周 SOP

### 5.1 周一 10:00 — 周计划（45min）

| 议程 | 内容 |
|------|------|
| 上周 ROI | 哪类模板 CTR 高 |
| 本周测款清单 | SKU + 目标条数 |
| 模板策略 | 本周主推 2 种模板 A/B |
| 资源 | BGM/音色是否需要更新 |

**周目标示例**：

| 指标 | 目标 |
|------|------|
| 周出片量 | 40 条 |
| 可用率 | ≥ 50% |
| 禁词事故 | 0 |
| 新模板测试 | 1 个 |

### 5.2 周三 15:00 — 质量复盘（30min）

1. 汇总驳回原因分布  
2. 播放 3 条「可用」+ 3 条「驳回」盲评  
3. 更新禁词库  
4. 反馈 Prompt 优化需求给 AI 工程师  

### 5.3 周五 16:00 — 周结（30min）

- 导出周 KPI  
- 归档 MP4 至 `{年}/{周}/` 目录  
- 清理 30 天前临时文件  
- 填写周复盘表

## 7. 异常处理

### 7.1 任务失败

| 状态 | 原因 | 处理 |
|------|------|------|
| extracting 失败 | OCR 无文字 | 补充商品文字信息手填 |
| scripting 失败 | LLM 超时 | 重试；换模型 |
| tts 失败 | 提供商限流 | 切换 TTS 提供商 |
| rendering 失败 | FFmpeg 错误 | 查日志；降分辨率 720p 重试 |
| qc rejected | 禁词 | 改脚本重新 render |

**升级**：同任务 3 次失败 → 技术支持。

### 7.2 成片质量问题

| 问题 | 处理 |
|------|------|
| 字幕不同步 | 手动调字幕时间轴；反馈工程 |
| 配音机械 | 换音色或降语速 |
| 画面单调 | V1.1 多图；临时加 BGM 增强 |
| 脚本生硬 | 换模板或人工重写后重新 TTS |

### 7.3 发布失败

| 现象 | 处理 |
|------|------|
| TikTok 授权过期 | 管理员重新 OAuth |
| 视频规格不符 | 检查分辨率/时长/编码 |
| 内容违规 | 平台反馈→更新禁词库 |

### 7.4 批量队列积压

- 积压 > 20 条：暂停新建，优先清空  
- 合成并发降至 1，避免 CPU 满载  
- 夜间安排大批量（22:00–06:00）

## 8. 模板运营策略

### 8.1 系统预设模板使用指南

| 模板 | 适用商品 | 钩子风格 |
|------|----------|----------|
| 痛点型 | 解决明确痛点的日用品 | 场景疑问 |
| 悬念型 | 新奇/黑科技 | 反差开场 |
| 测评型 | 3C、美妆 | 「我测了 X 天」 |
| 性价比型 | 价格敏感 | 数字对比 |
| 故事型 | 礼品、情感类 | 小故事 |

### 8.2 A/B 测款 SOP

1. 同 SKU 选 2 模板各 1 条  
2. 同时间段发布（间隔 < 2h）  
3. 记录 24h CTR、3s 跳出率  
4. 周三复盘纳入模板权重
