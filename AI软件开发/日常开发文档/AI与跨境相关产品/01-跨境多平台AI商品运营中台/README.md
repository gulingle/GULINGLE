# 跨境多平台 AI 商品运营中台

> **软件登记名**：跨境电商多平台智能商品运营管理系统 V1.0  
> **产品代号**：TradeMind-Ops  
> **版本**：V1.0 MVP  
> **最后更新**：2026-07-19

## 1. 产品定位

面向 Amazon、TikTok Shop、Shopify 等多平台跨境卖家的 **商品运营中台**，打通「采集 → 草稿 → AI 文案/图片建议 → 多平台刊登 → 库存订单同步」全链路。  
不是通用聊天机器人，而是可进入运营日流程、可计量 ROI 的生产力工具。

### 1.1 解决的核心痛点

| 痛点 | 现状 | 本产品方案 |
|------|------|------------|
| 多平台重复录入 | 同一 SKU 在 3+ 平台手工复制粘贴 | 一次草稿，多平台映射发布 |
| 文案质量不稳定 | 运营水平参差，转化率波动大 | AI 生成 + 平台规则校验 + 人工确认 |
| 采集到上架周期长 | 选品确认到 Listing 发布 > 2 天 | 目标 < 4 小时（含人工审核） |
| 库存不同步 | 超卖、断货投诉 | MVP 级库存/订单单向同步 |
| 缺乏过程审计 | 谁改了什么、何时发布不可追溯 | 全链路操作日志与版本对比 |

### 1.2 产品边界（做什么 / 不做什么）

**做：**
- 商品信息采集（URL/表格/竞品导入）
- 统一商品草稿库与 SKU 主数据
- AI 标题/五点/描述/关键词建议
- AI 主图场景建议与合规提示（不替代专业设计）
- Amazon / TikTok Shop / Shopify 刊登适配与发布
- 库存与订单 MVP 级同步（Webhook + 定时拉取）
- 任务中心、审批流、操作审计

**不做（V1.0 范围外）：**
- 全自动无人值守刊登（必须人工确认）
- 广告投放与竞价优化（见 03 号产品）
- 独立站主题建站（见 04 号产品）
- 深度 ERP/WMS 对接（仅 CSV/API 导出）
- 侵权图像检测（对接 07 合规系统，V1.0 仅禁词）

## 2. 目标用户

| 角色 | 使用场景 | 核心诉求 |
|------|----------|----------|
| 运营专员 | 日常上架、改价、库存维护 | 批量操作、少出错 |
| 运营主管 | 审核 AI 内容、分配任务 | 质量可控、进度可视 |
| 店主/老板 | 看板、ROI | 人效提升可量化 |
| 技术/实施 | 部署、对接 API | 私有化、密钥可控 |

## 6. 关键指标（健康线）

| 指标 | 定义 | V1.0 目标 |
|------|------|-----------|
| 上架时效 | 采集确认 → 发布成功 | < 4 小时 |
| AI 文案采纳率 | 运营采用 AI 建议字段比例 | > 60% |
| 刊登成功率 | 发布任务成功 / 总任务 | > 95% |
| 库存同步延迟 | 平台变更 → 中台更新 | < 15 分钟 |
| 人工干预率 | 需退回修改的草稿比例 | < 30% |

## 7. 快速启动（研发）

```bash
# 克隆仓库后
docker compose up -d          # PostgreSQL + Redis + MinIO
cp .env.example .env          # 配置 LLM API Key
npm run migrate               # 数据库迁移
npm run dev                   # 启动前后端
```

详细部署见 [02-技术架构与数据设计.md § 9 部署方案](./02-技术架构与数据设计.md)。
