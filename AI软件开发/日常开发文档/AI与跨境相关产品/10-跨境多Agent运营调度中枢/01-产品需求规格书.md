# 01-产品需求规格书

**产品名称**：跨境电商多智能体协同运营调度系统 V1.0  
**文档版本**：V1.0 | 2026-07-19  
**技术参考**：DeerFlow、atlas-mercator、n8n

---

## 1. 文档说明

### 1.1 目的
定义多 Agent 运营调度中枢如何编排 01–09 产品，形成可执行工作流、工具网关、人机协同闸口与全链路审计。

### 1.2 术语

| 术语 | 定义 |
|------|------|
| Agent | 具备角色 Prompt、工具权限的 LLM 执行单元 |
| Planner | 负责拆解用户目标为子任务的规划 Agent |
| Worker | 执行具体工具调用的领域 Agent |
| Tool Gateway | 统一封装 01–09 API 的工具层 |
| Workflow | 预定义或可视化的多步骤编排 |
| Human Gate | 必须人工 Approve 才能继续的节点 |
| Run | 一次工作流执行实例 |

## 4. 功能需求

### 4.1 模块总览

| 模块 | 说明 | 优先级 |
|------|------|--------|
| M1 编排引擎 | DAG 执行、状态机、重试 | P0 |
| M2 Agent 运行时 | Planner/Worker、上下文 | P0 |
| M3 工具网关 | 01–09 统一注册鉴权 | P0 |
| M4 人机协同 | 待办、审批、驳回 | P0 |
| M5 工作流设计器 | 可视化 + YAML | P1 |
| M6 审计与观测 | 日志、成本、追踪 | P0 |
| M7 自然语言入口 | Chat 触发工作流 | P1 |

### 4.2 M1 编排引擎

- DAG 节点类型：ToolCall、AgentCall、HumanGate、Parallel、Condition、Delay
- 执行策略：失败重试（可配置）、超时熔断、部分成功继续
- 上下文传递：JSON Context 在节点间合并
- 与 n8n 关系：复杂通用集成可走 n8n Webhook；跨境主路径走自研引擎

### 4.3 M2 Agent 运行时

#### 预置 Agent 角色

| Agent | 模型建议 | 工具权限 |
|-------|----------|----------|
| Planner | Claude/GPT-4 级 | 只读类 + 规划 |
| 选品顾问 | 中等模型 | intel.* |
| Listing 编辑 | 强模型 | ops.*, comp.scan |
| 合规官 | 强模型 | comp.* |
| 视觉导演 | 中等 | visual.* |
| 视频导演 | 中等 | video.* |
| 媒介 Agent | 中等 | creator.* |
| 巡检 Agent | 轻量 | auto.*, cs.* |

#### 上下文管理
- Run 级 Session：SKU、店铺、市场、用户意图
- Token 预算：单 Run 上限可配置
- Prompt 版本：A/B 与回滚

### 4.4 M3 工具网关

#### 工具描述规范（OpenAI Function 兼容）

```json
{
  "name": "comp.scan_listing",
  "description": "对 Listing 进行合规审查，返回风险分与问题列表",
  "parameters": { "listing_id": "string", "platform": "string" },
  "risk_level": "low",
  "requires_approval": false,
  "service": "07-compliance",
  "timeout_ms": 60000
}
```

#### 网关能力
- 统一 OAuth/API Key 注入（按租户）
- 速率限制、熔断（下游 5xx 连续 3 次暂停）
- 响应标准化：`{ ok, data, error, latency_ms, trace_id }`
- 敏感工具标记：`requires_approval=true`

### 4.5 M4 人机协同

- 待办中心：列出所有 Human Gate 项
- 审批动作：Approve / Reject / Edit & Approve
- 驳回后：Agent 根据意见重试或终止 Run
- 通知：钉钉/飞书/邮件/站内信

### 4.6 M6 审计与观测

- 全链路 Trace：run_id → step_id → tool_call_id
- 记录：输入输出摘要（PII 脱敏）、耗时、Token、操作者
- 看板：工作流成功率、平均耗时、人工干预率、成本

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 可靠性 | 编排引擎 99.9%；工具失败可重试 |
| 安全 | 工具权限按角色+租户；高危工具强制审批 |
| 性能 | 编排开销 P95 < 500ms（不含下游） |
| 合规 | 完整审计 365 天；支持导出 |

## 7. 验收标准

| 编号 | 验收项 | 通过标准 |
|------|--------|----------|
| AC-01 | WF-NEW-SKU | 端到端跑通 06→07→09→01，含 2 个人工闸口 |

| AC-03 | 工具网关 | 01–09 各至少 1 个工具可调用 |
| AC-04 | 审计 | 任意 Run 可还原完整调用链 |
| AC-05 | 熔断 | 模拟 07 宕机，Run 优雅失败并告警 |
| AC-06 | 审批 | Reject 后 Agent 按策略重试或终止 |
| AC-07 | 成本 | Token 与下游 API 调用可汇总到 Run |
