# 跨境竞品情报与选品决策系统

> **软件正式名称**：跨境电商竞品情报采集与选品决策分析系统 V1.0  
> **产品代号**：PickIntel  
> **主战场**：跨境选品、竞品监控、市场情报（Amazon / TikTok Shop / 独立站）

## 1. 产品定位

面向跨境卖家与选品团队，提供 **竞品/评论采集 + 多维评分模型 + 选品决策看板 + 日报预警** 的一体化情报系统。  
目标不是替代 firecrawl 等通用爬虫，而是构建 **跨境场景专属的采集策略、评分模型与决策工作流**。

### 1.1 解决的核心痛点

| 痛点 | 现状 | 本产品方案 |
|------|------|------------|
| 选品靠感觉 | 看爆款跟卖，同质化严重 | 数据驱动评分，多维筛选 |
| 竞品监控滞后 | 手动查 ASIN，价格变了不知道 | 自动采集 + 变动预警 |
| 评论分析费时 | 导出 Excel 人工读 | AI 情感分析 + 痛点提炼 |
| 情报分散 | 数据在 5 个工具里 | 统一看板 + 日报推送 |
| 决策无记录 | 选了什么、为什么选，没人记 | 选品决策日志 + 复盘 |

### 1.2 目标客户

| 客户类型 | 规模 | 核心诉求 | 推荐版本 |
|----------|------|----------|----------|
| 个人卖家 | 1–3 人 | 快速发现机会品 | 标准版 |
| 选品团队 | 5–15 人 | 批量监控、评分、协作 | 专业版 |
| 品牌/代运营 | 多品类 | 私有化、API、定制模型 | enterprise |

## 2. 产品边界

### 2.1 做什么

- 竞品采集：Amazon ASIN、TikTok 商品、独立站产品页（合规限速）
- 评论采集与分析：星级分布、情感、痛点/亮点提炼
- 多维评分：需求热度、竞争强度、利润空间、合规风险、供应链难度
- 选品看板：筛选、排序、收藏、标注、决策记录
- 日报/周报：新增竞品、价格变动、评论异常、机会品推荐
- 与 01 运营中台、07 合规系统联动（选品 → 上架闭环）

### 2.2 不做什么

- 不做侵权跟卖工具
- 不做刷单/虚假评论
- 不保证 100% 实时数据（受平台反爬限制，标注数据时效）
- 不替代专业市场调研机构

## 5. 快速启动检查清单

- [ ] 确认目标平台（Amazon US 优先）
- [ ] 配置采集账号/代理（合规限速）
- [ ] 导入首批监控 ASIN 清单（≥20 个）
- [ ] 校准评分模型权重（与运营顾问确认）
- [ ] 配置日报推送（邮件/企微/钉钉）
- [ ] 完成 5 个选品决策闭环验证（采集 → 评分 → 决策 → 导出到 01）
- [ ] 建立数据时效 SLA（价格 ≤6h、评论 ≤24h）
