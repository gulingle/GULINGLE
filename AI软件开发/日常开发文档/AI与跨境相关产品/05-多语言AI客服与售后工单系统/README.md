# 多语言 AI 客服与售后工单系统

> **软件正式名称**：跨境电商多语言智能客服与售后工单系统 V1.0  
> **产品代号**：CrossBorder-CS  
> **主战场**：跨境电商全渠道客服（独立站、Amazon、TikTok Shop、Email、社媒私信）

## 1. 产品定位

面向跨境卖家，提供 **RAG 智能客服 + 订单查询工具 + 人工升级 + 多渠道统一收件箱 + 售后工单闭环** 的一体化解决方案。  
目标不是替代 Dify/RAGFlow 等通用 AI 平台，而是构建 **跨境场景专属的客服知识库、订单工具链与 SLA 工单体系**。

### 1.1 解决的核心痛点

| 痛点 | 现状 | 本产品方案 |
|------|------|------------|
| 时差导致响应慢 | 欧美客户夜间咨询无人回复 | AI 7×24 即时响应，复杂问题排队人工 |
| 多语言沟通难 | 雇 3 种语言客服，月成本 $3000+ | RAG 多语言客服，人工仅处理升级单 |
| 订单查询效率低 | 客服切 3 个后台查订单 | 内置订单查询工具，一键拉取 |
| 售后无闭环 | 退款/换货靠 Excel 跟踪 | 标准化工单 + SLA 预警 |
| 知识分散 | FAQ 在 Notion、微信、脑子里 | 统一知识库 + 自动沉淀 |

### 1.2 目标客户

| 客户类型 | 规模 | 核心诉求 | 推荐版本 |
|----------|------|----------|----------|
| 小卖家 | 日咨询 <50 | 降本、基础自动回复 | 标准版 |
| 成长型卖家 | 日咨询 50–500 | 多语言、工单、数据报表 | 专业版 |
| 品牌/代运营 | 多店铺 | 统一收件箱、白标、API | 企业版 |

## 2. 产品边界

### 2.1 做什么

- RAG 智能客服：基于商品/政策/FAQ 知识库的多轮对话
- 订单查询工具：对接 Shopify/Amazon/自建站，查物流、退款状态
- 人工升级：置信度低/情绪激动/复杂售后自动转人工
- 多渠道：Web Widget、Email、Facebook/Instagram DM（API 对接）
- 售后工单：创建、分配、SLA、状态流转、模板回复
- 多语言：自动识别语种，≥8 种语言回复
- 质检与报表：会话评分、一次性解决率、响应时效

### 2.2 不做什么

- 不做呼叫中心（可对接 Twilio 等第三方）
- 不做 CRM 全功能（仅客服域客户画像）
- 不做广告投放
- 不替代 Dify/RAGFlow 通用编排（可集成其 RAG 能力，上层封装跨境业务）

## 5. 快速启动检查清单

- [ ] 确认接入渠道（至少 Web Widget + Email）
- [ ] 导入知识库：FAQ ≥50 条、退换货政策、物流说明
- [ ] 配置订单查询 API（Shopify/Amazon 其一）
- [ ] 设置人工升级规则与值班表
- [ ] 配置 SLA：首次响应 <5 分钟（AI）、<30 分钟（人工）
- [ ] 完成 20 条测试对话验收（含多语言、升级、工单创建）
- [ ] 上线质检抽检机制（≥10% 会话）
