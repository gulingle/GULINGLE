### 1.2 权利范围说明

本软件著作权涵盖以下**自有开发**部分的源代码及文档：

1. **RAG 客服引擎**：跨境场景知识检索策略、Prompt 模板、置信度判断、引用标注
2. **业务工具链**：订单查询、商品查询、退款政策查询等 Agent 工具
3. **升级判断引擎**：情绪识别、置信度阈值、升级规则配置
4. **工单管理系统**：工单 CRUD、状态流转、SLA 计时、分配规则
5. **多渠道适配层**：Web Widget、Email、社媒 DM 的统一接入与消息路由
6. **客服工作台**：会话管理、人工接管、并发处理、内部备注
7. **质检系统**：抽检规则、评分维度、报表生成
8. **知识库管理**：FAQ 管理、文档向量化、版本控制、未命中分析
9. **与跨境系统集成层**：与 01/04 系统的订单/商品数据同步

**不包含**：
- Dify/RAGFlow 核心引擎（若集成）
- LangChain 框架本身
- Qdrant/PGVector 向量数据库
- OpenAI/Claude 等 LLM 模型
- Shopify/Amazon 官方 SDK
- Socket.IO 等通信框架

### 3.2 各模块功能点明细

#### M02 RAG 客服模块

| 功能点 | 描述 |
|--------|------|
| 混合检索 | BM25 关键词 + 向量语义检索 |
| 重排序 | Reranker 提升检索精度 |
| Prompt 组装 | 上下文、知识库、工具结果组装 |
| 多语言回复 | 自动识别语种，对应语言生成 |
| 置信度计算 | 回复可信度评分 |
| 引用标注 | 标注知识来源 |
| 幻觉控制 | 无依据回答检测与拒绝 |

#### M05 工单管理模块

| 功能点 | 描述 |
|--------|------|
| 工单创建 | 手动/从会话自动创建 |
| 类型分类 | 退款/换货/物流/质量/其他 |
| 状态流转 | 新建→处理中→待客户→已解决→关闭 |
| SLA 计时 | 首次响应、解决时效自动计算 |
| SLA 预警 | 超时前自动告警 |
| 分配规则 | 轮询/按类型/按客服能力 |
| 附件管理 | 图片/视频凭证上传 |
