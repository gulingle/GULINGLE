## 6. 批产标准操作流程

```text
1. 确认 SKU 白底图（≥1500px，纯色底）
2. 选择工作流模板 + 品牌 Kit
3. 填写 params_override（卖点、场景风格）
4. 提交 batch_job → 等待队列
5. 自动品牌评分 + 07 合规（含文字图）
6. pending_review → 运营抽检 + 品牌经理审批
7. approved → Webhook 01 + 素材库 version+1
8. 导出多平台尺寸（如需）
```

### 6.1 输入质量标准

| 项 | 标准 |
|----|------|
| 白底图 | PNG/JPG，商品占比 ≥70%，无阴影过重 |
| 卖点文案 | 英文，无禁词（可先过 07 keywords/check） |
| SKU 信息 | 与 01 一致 |

### 6.2 输出验收标准

| 项 | 标准 |
|----|------|
| 分辨率 | 符合 export_preset |
| 商品变形 | 无明显拉伸 |
| 品牌色 | ΔE ≤ 15（系统评分 ≥85） |
| 文字 | 清晰可读，无 OCR 高风险 |
| 文件命名 | `{SKU}_main_amazon_v{n}.jpg` |

## 7. 异常处理

| 异常 | 处理 | 升级 |
|------|------|------|
| GPU OOM | 降低并发；换小分辨率模板 | 技术 |
| 队列积压 >2h | 暂停低优批量；加 GPU | 技术 |
| 批量失败 | 查 ComfyUI 日志；回滚工作流版本 | 设计师 |
| 品牌分普遍偏低 | 检查 Brand Kit 色值；调模板 | 品牌经理 |
| 07 合规大面积失败 | 检查 TextOverlay 文案；改 Prompt | 运营+合规 |
| 生成图商品不像 | 换 seed/加强 ControlNet；人工弃用 | 设计师 |
| 01 回写失败 | 重试 Webhook；手动上传 | 技术 |

## 8. 与 10 号中枢协同（WF-NEW-SKU 视觉节点）

当 10 触发 `visual.batch_generate`：
1. 运营收到「主图审批」Human Gate 待办
2. 必须在 4h SLA 内完成审批，否则 Run 暂停告警
3. Reject 需填写意见 → Agent 可触发重跑（换模板/参数）
