### 1.2 权利范围说明

登记范围包括自研：
- 工作流编排引擎与 ComfyUI 适配层
- 跨境主图/场景图/广告模板库及参数体系
- 品牌 Kit 一致性检测与评分算法
- 批产任务调度、GPU 队列管理
- 素材库版本管理与多平台导出预设
- 与合规审查、运营中台的联动逻辑
- 自研 Prompt 模板库（product-shots 风格结构化）

**不包含**：
- ComfyUI、Stable Diffusion、Flux 等开源模型与节点代码本体
- 客户商品图片版权
- 第三方字体/素材的授权（客户自行负责）

### 1.3 与开源边界

| 开源项目 | 许可证 | 使用边界 | 软著策略 |
|----------|--------|----------|----------|
| ComfyUI | GPL（注意传染性） | 建议 API 隔离调用，不静态链接混编 | 登记自研 Adapter + 模板库 |
| product-shots | 视具体仓库 | 仅借鉴 Prompt 结构，文案自写 | Prompt 库可登记 |
| open-design | 视具体仓库 | 借鉴 token 思路，数据模型自研 | Brand Kit 模块可登记 |
| SD/Flux 模型 | 各模型许可 | 客户侧部署，合同声明 | 不登记模型权重 |

**合规建议**：私有化部署 ComfyUI 为独立进程，通过 HTTP 调用，降低 GPL 传染风险；软著源代码不含 ComfyUI 源码树。
