# 09-跨境视觉工厂素材管理系统

> **软件登记名**：跨境电商商品视觉智能生成与素材管理系统 V1.0  
> **产品代号**：VisualFactory / VF-09  
> **版本**：V1.0（文档基线：2026-07）  
> **技术参考**：ComfyUI（工作流引擎）、product-shots（商品摄影 Prompt）、open-design（品牌模板）

## 1. 产品定位

为跨境卖家提供**主图 / 场景图 / 广告素材**的批量智能生成与统一素材库管理。通过可编排的 AI 图像工作流（类 ComfyUI）+ 品牌一致性约束 + 版本管理，将视觉产出从「设计师手工」升级为「运营自助批产 + 人工抽检」。

### 1.1 解决的核心痛点

| 痛点 | 现状 | 本系统方案 |
|------|------|------------|
| 主图产出慢 | 外包 3–5 天/套 | 模板工作流，分钟级批产 |
| 品牌风格不统一 | 多设计师各做各的 | 品牌 Kit：色板/字体/构图规则 |
| 素材散落 | 网盘/微信/file 混乱 | 素材库：SKU 维度版本管理 |
| 平台尺寸各异 | 手工改尺寸 | 多平台导出预设（Amazon/TikTok/Meta） |
| 合规风险 | 夸大/侵权图 | 对接 07 图文合规审查 |

### 1.2 产品边界

**做什么：**
- 工作流编排：抠图→场景合成→文字叠加→尺寸导出
- 主图、场景图、广告 Banner、A+ 模块图批产
- 品牌 Kit 管理与一致性评分
- 素材库：上传、AI 生成、标签、审批、回写 01
- ComfyUI 工作流 JSON 导入/托管（私有化）

**不做什么：**
- 不承诺 100% 免修图（默认人工抽检闸口）
- 不替代专业品牌 VI 设计（提供模板级一致性）
- 不托管客户未授权的模特/场景版权素材
