# 08-TikTok达人匹配与合作SOP系统

> **软件登记名**：TikTok达人合作匹配与营销协同管理系统 V1.0  
> **产品代号**：CreatorSOP / CS-08  
> **版本**：V1.0（文档基线：2026-07）  
> **开源参考**：`tiktok-creator-sop-tool`（达人库结构、outreach 模板思路，须二次开发后商用）

## 1. 产品定位

为 TikTok Shop 与品牌出海团队提供**达人发现 → 智能匹配 → Outreach 触达 → 合作跟进 → 内容交付 → ROI 复盘**的全流程 SOP 管理系统。将散落在表格、私信、微信群里的达人合作流程产品化，并与 02 成片系统、09 视觉工厂、01 运营中台联动。

### 1.1 解决的核心痛点

| 痛点 | 现状 | 本系统方案 |
|------|------|------------|
| 达人信息分散 | Excel + 截图，无法检索 | 结构化达人库 + 标签 + 历史合作 |
| 匹配靠感觉 | 品类/粉丝/互动率无标准 | 多维度匹配评分 + AI 推荐理由 |
| Outreach 效率低 | 复制粘贴，无跟进 | 模板化私信/邮件 + 状态机 + 提醒 |
| 合作过程失控 | 寄样/脚本/发布无节点 | SOP 看板 + 里程碑 + 逾期告警 |
| ROI 算不清 | 佣金与 GMV 对不上 | 归因链接 + 合作 ROI 仪表盘 |

### 1.2 产品边界

**做什么：**
- 达人库 CRUD、导入、去重、标签体系
- 基于商品/品类的达人匹配与排序
- Outreach 草稿生成（多语言）、发送记录、回复跟踪
- 合作 SOP：邀约→议价→寄样→脚本→拍摄→发布→结算
- ROI 统计：曝光、点击、转化、CPA、ROAS
- 与 02/09/01/10 的标准 API 对接

**不做什么：**
- 不代替 TikTok 官方达人广场 API 的全部能力（受平台接口限制）
- 不自动批量私信（遵守平台 ToS，提供草稿 + 人工发送）
- 不做达人独家经纪代理功能

## 2. 目标用户与角色

| 角色 | 职责 | 系统权限 |
|------|------|----------|
| 达人运营 | 日常匹配、outreach、跟进 | 达人库编辑、合作创建 |
| 媒介主管 | 策略、预算、审批 | 看板、审批高价合作 |
| 内容运营 | 脚本、素材交付 | 查看合作、上传 Brief |
| 财务 | 佣金结算 | 结算单只读/确认 |
| 店长/老板 | ROI 复盘 | 报表只读 |
