# 03-实战运营手册

> **软件名称**：跨境卖家店铺智能巡检与广告优化辅助系统 V1.0  
> **适用版本**：V1.0 MVP（本地部署）  
> **最后更新**：2026-07-19

---

## 1. 手册目的

本手册供 **店主、广告投手、运营、系统管理员** 在本地部署环境下执行日常巡检、告警响应与周期性复盘。强调 **限速熔断** 操作纪律，确保账号安全。

---

## 2. 角色职责

| 角色 | 日常职责 | 系统权限 |
|------|----------|----------|
| 店主 | 查看总览、重大异常决策 | 全部只读 + 告警 |
| 广告投手 | 广告日报、优化建议参考 | 广告模块 |
| 运营专员 | Listing 异常跟进 | Listing 模块 |
| 系统管理员 | 部署、Profile、限速、熔断解除 | 系统配置 |
| 客成/实施 | 安装交付、培训 | 安装向导 |

**纪律**：
- 仅管理员可解除熔断  
- 投手 **不得** 要求开启自动改价（V1.0 不支持）  
- 验证码必须人工处理，禁止脚本绕过

## 3. KPI 指标体系

### 3.1 巡检 KPI

| KPI | 公式 | 日目标 | 周目标 | 月目标 |
|-----|------|--------|--------|--------|
| 巡检成功率 | 成功任务/总任务 | ≥ 95% | ≥ 96% | ≥ 97% |
| 日报准时率 | 8:00 前生成/应生成天数 | 100% | 100% | ≥ 98% |
| 异常检出数 | 真实异常/巡检发现 | 追踪 | - | 准确率 ≥ 80% |
| 误报率 | 误报/(误报+真阳性) | < 20% | < 15% | < 10% |
| 熔断次数 | 月累计 | 0 为最佳 | ≤ 1 | ≤ 2 |

### 3.2 业务价值 KPI

| KPI | 说明 | 目标 |
|-----|------|------|
| 异常响应时效 | 告警→人工确认 | P0 < 2h |
| ACOS 异常发现 | 较均值飙升 > 30% 当日发现 | 100% |
| Suppressed 发现 | 状态变更后首次巡检检出 | < 4h |
| 人工巡检时间节省 | 对比启用前后 | ≥ 60% |

### 3.3 系统 KPI

| KPI | 目标 |
|-----|------|
| CDP 连接可用率 | ≥ 99% |
| 本地服务 uptime | ≥ 99% |
| 备份成功率 | 100% |

## 7. 异常处理手册

### 7.1 CDP 连接失败

| 现象 | 原因 | 处理 |
|------|------|------|
| connection refused | Chrome 未启动 | 启动 Chrome + 调试端口 |
| disconnected | Chrome 崩溃 | 重启 Chrome；检查 Profile |
| 多 Profile 冲突 | 端口占用 | 每 Profile 独立端口 9222/9223 |

**SOP**：
1. 检查 Chrome 进程  
2. 访问 `http://127.0.0.1:9222/json` 应有响应  
3. 控制台「测试连接」  
4. 仍失败 → 重启 Docker + Chrome  

### 7.2 熔断触发

| 触发原因 | 立即动作 |
|----------|----------|
| 验证码 | **停止一切自动化**；人工登录处理验证码 |
| 频率限制 | 等待 24h；检查是否手动操作冲突 |
| 连续失败 | 查日志；可能页面改版 |
| 登录失效 | 重新登录卖家后台 |

**解除熔断 SOP**（仅管理员）：
1. 确认验证码已清除 / 登录正常  
2. 手工访问广告报表页，确认可正常浏览  
3. 控制台 → 熔断 → 「解除」并填写原因  
4. 先执行一次手动巡检验证  
5. 恢复定时任务  

**严禁**：未人工确认直接解除熔断。

### 7.3 巡检任务失败

| 错误 | 处理 |
|------|------|
| selector not found | 页面改版；联系技术支持更新脚本 |
| timeout | 网络慢；增加 timeout；检查 VPN |
| empty table | 日期范围错误；检查配置 |
| 部分字段为空 | 记录；不影响其他字段入库 |

**重试策略**：自动重试 2 次；仍失败标 failed，人工介入。

### 7.4 日报未生成

| 检查项 | 处理 |
|--------|------|
| 采集是否成功 | 先修采集 |
| LLM 不可用 | 切换 Ollama/云端 |
| 定时任务禁用 | 重新启用 |
| 补发 | 手动点击「生成日报」 |

### 7.5 告警风暴

- 同 ASIN 4h 内去重  
- 批量 Suppressed → 合并为 1 条 P0  
- 检查是否平台系统性故障

## 8. 限速与安全配置

### 8.1 默认限速（不建议随意调低）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 操作间隔 | 3000ms | 页面操作最小间隔 |
| 日操作上限 | 200 次 | 防风控 |
| 熔断时长 | 24h | 触发后冷却 |

### 8.2 调参审批

- 提高日上限 > 300：店主书面批准  
- 降低间隔 < 2000ms：**禁止**（V1.0）  

### 8.3 Chrome 使用规范

- 巡检时段避免人工同时操作同一 Profile  
- 不使用自动化 Profile 浏览无关网站  
- 定期清理缓存但 **不** 清除登录 Cookie
