# 跨境卖家后台 AI 自动化助手

> **软件登记名**：跨境卖家店铺智能巡检与广告优化辅助系统 V1.0  
> **产品代号**：SellerGuard  
> **版本**：V1.0 MVP  
> **最后更新**：2026-07-19

## 1. 产品定位

面向 Amazon、TikTok Shop 等卖家后台的 **本地部署智能巡检与广告优化辅助系统**。  
通过浏览器 CDP（Chrome DevTools Protocol）在卖家本机执行只读/半自动任务：广告报表巡检、Listing 健康检查、异常告警，并提供限速熔断保障账号安全。

### 1.1 解决的核心痛点

| 痛点 | 现状 | 本产品方案 |
|------|------|------------|
| 后台数据分散 | 广告/库存/评价需多页切换 | 统一巡检面板 + 日报 |
| 异常发现滞后 | ACOS 飙升、差评堆积后才知道 | 定时巡检 + 阈值告警 |
| 重复劳动多 | 每日下载报表、检查状态 | 自动化采集 + AI 摘要 |
| 云端 RPA 风险 | Cookie 上云、账号关联 | **本地部署**，密钥不出本机 |
| 误操作风险 | 自动化乱点导致封号 | 限速、熔断、人工确认闸门 |

### 1.2 产品边界

**做：**
- 本地 Docker / 桌面端部署
- 浏览器 CDP 连接（用户自有 Chrome Profile）
- 广告报表只读采集（SP/SB/SD MVP 先做 SP）
- Listing 状态巡检（在售/ suppressed/ 库存预警）
- AI 异常摘要与优化建议（只读报告，不自动改价）
- 限速策略（请求间隔、每日上限）
- 验证码/异常熔断与告警

**不做（V1.0）：**
- 云端代登录卖家账号
- 自动修改广告竞价/预算（仅建议，V1.1 可选半自动）
- 批量下单、刷单等违规操作
- 多平台深度 API（优先 CDP 适配后台页面）

## 5. 架构概览

```text
┌──────────────────────────────────────────────────────────┐
│                    用户本机（本地部署）                      │
│  ┌─────────────┐    CDP     ┌─────────────┐              │
│  │ Chrome      │◄──────────►│ Agent 引擎   │              │
│  │ 卖家后台     │            │ 限速/熔断    │              │
│  └─────────────┘            └──────┬──────┘              │
│                                    │                      │
│  ┌─────────────┐            ┌──────▼──────┐              │
│  │ 本地控制台   │◄──────────►│ 巡检调度器   │              │
│  │ Web UI      │            │ 任务队列     │              │
│  └─────────────┘            └─────────────┘              │
└──────────────────────────────────────────────────────────┘

    只读报告 / AI 建议（不自动执行写操作）
```
